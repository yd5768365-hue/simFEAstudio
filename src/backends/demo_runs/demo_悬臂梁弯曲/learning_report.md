# 学习报告：悬臂梁弯曲

## 运行摘要

- **求解器**: CalculiX 2.10
- **运行时间**: 0.1 秒
- **状态**: 成功完成

## 关键结果

| 指标 | 值 |
|------|-----|
| 最大位移 | 8.93 mm |
| 最大 von Mises 应力 | 37.50 MPa |

## 与解析解对比

Euler-Bernoulli 梁理论：
- δ_max = PL³/(3EI) = 8.93 mm ✓
- σ_max = Mc/I = 37.50 MPa ✓

FEM 结果与解析解吻合，验证了 CalculiX 对此类线弹性问题的求解精度。

## 学习收获

1. 悬臂梁是验证 FEM 求解器准确性最经典的基准案例之一
2. 对于简单几何和均匀材料，粗网格已足够获得精确结果
3. 求解器输出（.frd）可以转换为 VTK 格式进行 3D 可视化
