# SimFEA-Lab Core 求解器开发

> 从零手写 FEM 求解器，触碰底层逻辑。

## 当前状态

| 项目 | 状态 |
|------|------|
| 语言 | C++ (CMake 构建) |
| 已实现 | 1D 杆单元 (bar1d) |
| 精度 | 与解析解一致 (误差 < 1e-12) |
| 下一步 | 梁单元、2D 平面单元 |

## 已实现功能

- [x] 1D 杆单元刚度矩阵 (2×2)
- [x] 全局刚度矩阵组装
- [x] Dirichlet 边界条件施加（划行划列法）
- [x] 线性方程组求解（直接法）
- [x] 应变/应力恢复
- [x] 支反力计算
- [x] 解析解对比验证
