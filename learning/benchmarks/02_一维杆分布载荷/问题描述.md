# Case 2: 一维杆均布轴力 (Rod with Distributed Axial Load)

## 物理问题描述

一根等截面直杆，左端固定，右端自由，沿轴向受均布载荷 $q$（单位长度的力）。与 Case 1（端部集中力）不同，载荷沿杆长连续分布，位移场不再是线性。

```
  固定端                                    自由端
  ┌──────┬─────────────────────────────────┬──────┐
  │  //  │  q ↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓  │      │
  └──────┴─────────────────────────────────┴──────┘
  x = 0                                   x = L
```

**几何与材料参数：**

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 杆长 | L | 100 | mm |
| 截面积 | A | 10 | mm² |
| 弹性模量 | E | 210 000 | MPa |
| 均布载荷 | q | 10 | N/mm |

> 选用 $q = 10\ \text{N/mm}$ 使得固定端最大应力 $\sigma(0) = 100\ \text{MPa}$，与 Case 1 一致，便于横向对比。

## 控制方程

一维弹性杆受分布载荷 $q(x)$ 的位移控制方程为：

$$
\frac{d}{dx}\left(EA\frac{du}{dx}\right) + q = 0
$$

由于 $EA$ 为常数且 $q$ 均匀，简化为：

$$
\frac{d^2u}{dx^2} = -\frac{q}{EA}, \quad x \in [0, L]
$$

## 边界条件

- **Dirichlet（位移边界）**：固定端位移为零

  $$u(0) = 0$$

- **Neumann（力边界）**：自由端轴力为零（无集中外力）

  $$EA \cdot u'(L) = 0$$

## 解析解推导

一次积分：

$$u'(x) = -\frac{q}{EA}x + C_1$$

由 $u'(L) = 0$：

$$-\frac{qL}{EA} + C_1 = 0 \quad\Rightarrow\quad C_1 = \frac{qL}{EA}$$

得应变场：

$$\varepsilon(x) = u'(x) = \frac{q}{EA}(L - x)$$

二次积分：

$$u(x) = \frac{q}{EA}\left(Lx - \frac{x^2}{2}\right) + C_2$$

由 $u(0) = 0$：

$$C_2 = 0$$

得位移场（二次分布）：

$$u(x) = \frac{q}{2EA}\left(2Lx - x^2\right)$$

应力场（线性分布，固定端最大，自由端为零）：

$$\sigma(x) = E\varepsilon(x) = \frac{q}{A}(L - x)$$

## 参考值

| 物理量 | 表达式 | 数值 |
|--------|--------|------|
| 自由端位移 $u(L)$ | $\dfrac{qL^2}{2EA}$ | $0.0238\ldots\ \text{mm}$ |
| 固定端应力 $\sigma(0)$ | $\dfrac{qL}{A}$ | $100\ \text{MPa}$ |
| 自由端应力 $\sigma(L)$ | $0$ | $0\ \text{MPa}$ |

**精确值：**

$$u(L) = \frac{10 \times 100^2}{2 \times 210\,000 \times 10} = \frac{100\,000}{4\,200\,000} = \frac{1}{42} = 0.0238095238\ldots\ \text{mm}$$

## 与 Case 1 的对比要点

| 特征 | Case 1（端部拉力） | Case 2（均布载荷） |
|------|-------------------|-------------------|
| $u(x)$ 形式 | 线性 | 二次 |
| $\sigma(x)$ 形式 | 均匀 | 线性递减 |
| 最大应力 | 100 MPa（全域） | 100 MPa（仅固定端） |
| $u(L)$ | 0.0476190476 mm | 0.0238095238 mm |

Case 2 的位移仅为 Case 1 的一半——均布载荷的合力（$qL = 1000\ \text{N}$）作用于形心（$L/2$），等效集中力产生的位移恰好减半。

## 求解器配置参考

- **CalculiX**: T3D2 杆单元，需多个单元（建议 10+）以捕捉二次位移场
- **ANSYS MAPDL**: LINK180 杆单元，同上需网格加密
- **PINN**: 无因次化 PyTorch 实现，损失函数需包含分布载荷项
