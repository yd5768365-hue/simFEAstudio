# Case 3: 圆孔板应力集中 (Hole-in-Plate Stress Concentration)

## 物理问题描述

矩形平板中心有一圆孔，上下两端受均匀拉伸应力 σ_0。圆孔边缘产生应力集中，最大周向应力出现在孔边水平方向。属于 2D 平面应力问题。

```
          σ_0 (均匀拉伸)
    ┌──────────────────────────┐
    │                          │
    │           ╭───╮          │
    │           │ ○ │  d=20    │ ← H=200
    │           ╰───╯          │
    │                          │
    └──────────────────────────┘
          σ_0              W=100
```

**几何与材料参数：**

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 板宽 | W | 100 | mm |
| 板高 | H | 200 | mm |
| 孔径 | d | 20 | mm |
| 板厚 | t | 1 | mm |
| 弹性模量 | E | 210000 | MPa |
| 泊松比 | ν | 0.3 | — |
| 远端拉伸应力 | σ_0 | 100 | MPa |

## 控制方程

2D 平面应力弹性力学方程（Airy 应力函数 φ 满足双调和方程）：

$$\nabla^4 \phi = 0$$

## 解析解（无限大板）

Kirsch 解给出了无限大板圆孔问题的应力分布：

$$\sigma_{\theta\theta}(r,\theta) = \frac{\sigma_0}{2}\left(1 + \frac{a^2}{r^2}\right) - \frac{\sigma_0}{2}\left(1 + 3\frac{a^4}{r^4}\right)\cos 2\theta$$

孔边（r=a，θ=90°）最大周向应力：

$$\sigma_{\max} = 3\sigma_0$$

应力集中系数：**K_t = 3.0**

## 有限宽度修正

当 d/W = 0.2，H/W = 2 时，有限宽度修正：
- **K_t ≈ 2.73**（Peterson, Stress Concentration Factors）

## 参考值

| 物理量 | 表达式 | 数值 |
|--------|--------|------|
| 远端应力 | σ_0 | 100 MPa |
| 孔边最大应力（无限板）| 3σ_0 | 300 MPa |
| 孔边最大应力（有限板，d/W=0.2）| K_t·σ_0 | ≈273 MPa |
| 应力集中系数 K_t | — | 2.73 |
