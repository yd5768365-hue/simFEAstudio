Case 2: 悬臂梁端部弯曲 (Cantilever Beam Bending)

物理问题描述

一根等截面矩形悬臂梁，左端固支，右端受垂直集中力 P 作用。属于 Euler-Bernoulli 梁弯曲问题。

  固定端                                  自由端 → P (向下)
  ┌──────┬──────────────────────────────┬──────┐
  │  //  │      矩形截面 b × h          │  ↓ P │
  └──────┴──────────────────────────────┴──────┘
  x = 0                                  x = L
