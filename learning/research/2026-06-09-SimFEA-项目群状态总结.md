# 2026-06-09 SimFEA 项目群状态总结

## 三个项目

| 项目 | 定位 | 语言 | 状态 |
|------|------|------|------|
| SimFEA Studio | 仿真方法对比工作台 | Vue + Python + Tauri | 可用 |
| SimFEA-Lab Core | 手写 FEM 求解器 | C++ | 起步 |
| cae-preflight | inp 文件预检查 | Python | 已集成入 Studio |

## SimFEA Studio

桌面应用，管理求解器、提交运行、归档结果、对比方法。

**前端：** 6 个视图（作业/学习/问答/实验/基准/工具），7 槽位仿真流程，VTK.js 3D 可视化。

**后端：** FastAPI，运行管理（本地/SSH/Slurm/Docker），SSE 实时日志，结构化学习笔记+报告。

**AI：** Ollama 本地 LLM（qwen2.5:7b）+ 嵌入模型（nomic-embed-text）。知识库 RAG（文档分块→嵌入→检索→LLM 回答），自然语言→求解器配置翻译，多轮对话。

**基准资产：** 2 个 case（杆拉伸、分布载荷），4 路对比（解析解/PINN/CalculiX/ANSYS）。

## SimFEA-Lab Core

C++ 1D 杆单元 FEM 求解器。单元刚度计算→全局组装→边界条件处理→求解→应变应力恢复→解析解对比。源码参考库包含 32 个开源求解器。

## 架构判断

三个项目边界清晰：
- Studio 负责案例管理、方法对比、结果展示
- Core 负责求解器底层逻辑
- preflight 负责输入验证

技术栈合理：Vue (UI) + Python (后端) + C++ (求解器) + Tauri (桌面壳)。

## 不足

1. Benchmark case 太少（2 个 1D 问题）
2. AI 回答质量未系统验证
3. comparison.csv 靠手动填写
4. 没有外部用户反馈

## 下一步

停止加功能。积累 benchmark case——悬臂梁弯曲、圆孔板应力集中、热传导。每个 case 四件套：problem.md + analytic.py + 求解器输入 + comparison.csv。用 SimFEA-Lab Core 的输出作为新方法加入对比表。
