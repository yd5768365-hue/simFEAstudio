# AI 在工业流程中的落地与赋能分析报告

> 执行摘要：当前工业 AI 最成熟的方向集中在设备健康监测与预测性维护、视觉质量检测、工艺优化、能耗管理，以及供应链预测与排产调度。工业 AI 不是单纯"训一个模型"，而是"数据面、应用面、治理面"协同推进的系统工程。

---

## 一、场景与技术路径

工业 AI 优先场景的选择原则：**价值密度高、数据链条短、闭环动作清晰**。

| 场景 | 关键环节 | 典型 AI 技术 | 预期收益 |
|------|---------|-------------|---------|
| 预测性维护 | 关键设备、阀门、泵、压缩机 | 多变量异常检测、RUL、混合机理+ML | 减少计划外停机、优化备件 |
| 质量检测 | AOI、外观终检、焊点/涂胶 | 分类、目标检测、分割、异常检测 | 提升一次通过率、降低漏检 |
| 工艺优化 | 参数设定、良率稳定、换线 | 软测量、时序预测、约束优化、数字孪生 | 减少良率损失、提高 OEE |
| 能耗管理 | 公用工程、空压、冷站、锅炉 | 负荷预测、异常检测、能源优化 | 降低单位能耗和碳排 |
| 供应链与调度 | 需求预测、库存、排产、冷链 | 概率预测、库存优化、OR+ML 排产 | 提高服务水平、降低库存 |

---

## 二、架构模式

成功项目具备三个共同特征：

1. **协议打通**：以 OPC UA、MQTT 等开放协议打通 OT/IT
2. **混合架构**：边缘采集与预处理 + 云端训练与治理 + 统一监控告警
3. **流程嵌入**：模型输出嵌入 CMMS、MES、SAP、排产或能源管理流程

反面案例：GE Predix — "平台先行、场景后置"，最终收缩回归核心客户。

## 三、实施步骤

```
业务目标与基线 → 数据盘点与接口打通 → PoC 影子模式
    → KPI 达标？→ Pilot 接入 MES/CMMS/排产
    → ROI 达标？→ 多线多厂复制 → 模型监控与治理常态化
```

| 阶段 | 周期 | 关键里程碑 | 停/进决策点 |
|------|------|-----------|------------|
| 诊断与选题 | 2-4 周 | 明确痛点、基线 KPI、设备清单、接口清单 | 无明确 KPI / 无 owner / 无数据 → 停止 |
| 数据与底座 | 4-8 周 | OPC UA/MQTT/历史库最小接入；统一数据字典 | 数据完整率低、时间戳不同步 → 先补数据 |
| PoC | 6-10 周 | 影子模式上线；基线对比；第一版 SOP | 无法嵌入作业流程 → 不进入 Pilot |
| Pilot | 8-16 周 | 与 CMMS/MES/SAP 联动；值班与回退机制 | KPI 无改善或采纳率低 → 回 PoC |
| 规模化 | 3-9 月 | 模板化复制；监控、版本、审计上线 | 复制需重做 80% 以上 → 暂停扩张 |
| 持续运营 | 长期 | 漂移监控、再训练、审计、价值复盘 | 季度复盘决定扩容或收缩 |

### 预算参考（中国大陆，单厂）

| 档位 | 范围 | 适用边界 |
|------|------|---------|
| 低 | 50-150 万 | 单厂单场景；已有 MES/SCADA |
| 中 | 200-800 万 | 单厂多线或 2-3 场景；需系统集成与 MLOps |
| 高 | 1000-5000 万+ | 多厂复制、统一数据底座、数字孪生、治理体系 |

## 四、数据与工程难点

| 难点 | 表现 | 方案 |
|------|------|------|
| 数据质量与标签 | 缺陷样本少、工单不规范、批次对不上 | 数据字典 + 元数据强绑定 + 预标注 |
| 实时性与边缘带宽 | 上云太慢、视觉数据爆炸 | 边缘预处理 + 选择性上传；毫秒级决策放边缘 |
| OT/IT 融合 | PLC/DCS/SCADA/ERP/MES 断裂 | OPC UA/MQTT 统一数据面；工业服务总线 |
| 模型部署与监控 | 上线后精度掉、无人维护 | MLOps：漂移检测、A/B 测试、再训练触发 |
| 算力与边缘部署 | 工控机资源小、GPU 投入难 | 模型压缩 + 推理优化；GPU 不作为先验假设 |
| 安全与合规 | OT 暴露、模型不可追溯 | ISA/IEC 62443 全生命周期安全；生成式 AI 仅辅助 |

## 五、组织与治理

**四层责任链**：

- **现场操作员** → 告警确认与反馈标注
- **工艺/设备工程师** → 根因验证和业务闭环
- **OT/IT/数据团队** → 接口、部署、回滚与监控
- **管理层** → 月度 AI steering committee，审视 ROI、风险与复制节奏

培训方式：**角色化训练**，不是一次性大课。班组长学判断信任/复核时机；工艺工程师学特征与误报根因；IT/OT 学部署与故障回退；管理层学基线 KPI 停/进决策。

## 七、核心结论

> 工业 AI 真正可持续的方向不是"一个万能大模型统治工厂"，而是"以工业数据与工作流为核心的多模型协同体系"：边缘侧做低时延感知与执行，云侧做训练与治理，人始终保留审批权与回退权。胜负手不在概念，在于是否把场景、数据、架构、流程和治理同时做成可复制模板。
