SimFEA Studio is the independent workflow and comparison workbench project.

Development logs:

- Formal long-term logs must be written to `H:\知识库\我的ai时代知识库\有限元与仿真\独立开发求解器--日志`.
- Existing historical logs under `docs/` are kept as project history.
- New project direction notes, case-comparison notes, and cross-project progress with SimFEA-Lab should point to the shared knowledge-base log folder.

Project boundary:

- Do not merge SimFEA Studio with SimFEA-Lab Core.
- SimFEA Studio manages cases, workflows, comparisons, and presentation.
- SimFEA-Lab Core develops the finite element solver logic.
