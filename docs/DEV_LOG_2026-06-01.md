## 一、COMSOL 风格工作流 UI 重设计

### 从横向卡片 → 竖排树形节点

```
旧：7 个横向排列的 node 卡片，带独立下拉框
新：COMSOL Model Builder 风格的竖排树形节点
```

**改动文件**：`app/App.vue`、`app/style.css`

**具体变化**：
- 节点改为竖排树形（`.model-tree` + `.tree-node`）
- 每个节点左侧有状态边框（绿色=就绪、灰色=待输入、橙色=运行中、红色=阻塞）

- 分组标题：前处理（几何/网格/材料/边界）、求解、后处理（后处理/验证）

### 属性面板可编辑

- 全局设置始终可见：作业名称 + 侧车连接状态

- geometry 节点：上传文件列表 + 格式检测提示
- 其他节点：工具选择 + 节点详情

### 右键菜单

- 右键节点 → 弹出上下文菜单
- **切换工具**：直接选择该节点的可用工具
- **Update**：从此节点开始增量执行（只跑变动部分和下游）
- **重置为默认**：恢复默认工具选择

### 节点启用/禁用

- 每个节点左侧有绿色方块开关
- 禁用的节点变灰、文字加删除线
- 三个预设：完整流程 / 仅求解 / 几何+求解

### 键盘导航

- ↑↓ 箭头键在节点间切换
- 循环滚动

## 八、已修复问题

### ✅ WebView2 侧车离线（已修复）

**根因**：Tauri 自定义协议下页面 `hostname` 是 `tauri.localhost`，`apiBaseUrl` 推导为 `http://tauri.localhost:8008`，请求发不到侧车。

**修复**：
- `app/App.vue` line 12：API 地址推导增加回落 `http://localhost:8008`
- 新建 `app/utils/apiBaseUrl.ts`：提取 `apiBaseUrl` 为独立可测试函数
- 新建 `app/utils/apiBaseUrl.test.ts`：单元测试覆盖
    
**验证**：27 tests passed（含新增 apiBaseUrl test）

### ✅ Docker CLI 不在 PATH（已修复）

**根因**：Docker Desktop 把 `docker.exe` 装在 `C:\Program Files\Docker\Docker\resources\bin\`，不在系统 PATH。

**修复**：
- `main.py` line 175：新增 `docker_cli_executable()` 函数，先查 `shutil.which("docker")`，再兜底 Windows 默认路径
- `_execute_docker_run()` 改用 `docker_cli_executable()` 获取 Docker CLI 路径

**验证**：`docker_cli_executable()` 解析到 `C:\Program Files\Docker\Docker\resources\bin\docker.exe`

## 十、Docker 全栈容器化

### 架构

```
docker-compose up
  └─ simfea/studio:latest
       ├─ nginx :3000 → Vue 前端静态文件
       ├─ FastAPI :8008 → Python 侧车
       ├─ supervisor → 管理 nginx + 侧车进程
       ├─ calculix-ccx + gmsh → 内置求解器
       └─ /workspace ← 挂载卷 (run archives, config)
```

用户只需 `docker compose up`，浏览器打开 `localhost:3000` 即可使用完整工作台。

### 新增文件

| 文件 | 说明 |
|------|------|
| `docker/Dockerfile` | 单阶段构建：ubuntu + Python + 求解器 + nginx + supervisor |
| `docker/nginx.conf` | 前端静态文件 + `/v1/` API 反向代理到侧车 |
| `docker/supervisord.conf` | 管理 nginx + FastAPI 侧车 |
| `docker-compose.yml` | 一键启动：`docker compose up --build` |
| `.dockerignore` | 排除 node_modules、.simfea、src-tauri 等 |

### 构建过程

1. 前端本地构建：`pnpm build` → `dist/`
2. Docker 镜像：复制 `dist/` + `src/backends/` + `pyproject.toml`
3. 安装 Python venv + pip install
4. 配置 nginx + supervisor

### 遇到的问题

**问题**：Docker 构建上下文过大（4.23GB），Docker Desktop 崩溃
- 原因：`node_modules`、`.simfea`、`src-tauri/target` 未排除
- 解决：添加 `.dockerignore`，排除不必要目录

**问题**：多阶段构建（node:alpine）增加复杂度 + Docker Desktop 在网络差时频繁 EOF
- 解决：前端本地构建，Dockerfile 只复制预构建产物，单阶段完成

**问题**：Docker Desktop 在 Windows 上不稳定（WSL2 后端频繁断开）
- 状态：Dockerfile 代码已完成，待 Docker Desktop 稳定后验证完整构建

### Tauri 桌面壳定位

```
Docker 镜像 → 浏览器访问（主力）
Tauri 安装包 → 原生桌面体验（可选）
```

两者共享同一套 API，用户按需选择。桌面壳不进 Docker 容器（需要 WebView2 + 系统窗口 API）。
