3. 前端新增“工具链管理”页面：
   - 左侧导航增加“工具链”入口。

4. 路径保存会写回配置：
   - `选择路径` 会更新 `.simfea/config.json` 中对应求解器的 `executable`。
   - PrePoMax 会同步更新 `prepomax` 和 `prepomax-regenerate` 两个配置项，避免前处理和再生成路径不一致。

5. 已处理 PrePoMax 的特殊验证行为：
   - `PrePoMax --help` 会输出帮助信息，但退出码可能不是 0。
   - 当前验证规则允许“退出码为 0”或“输出中明确出现工具帮助/版本信息”视为通过。
