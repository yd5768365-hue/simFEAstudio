## 架构判断

SSH、WSL、Docker、本地 shell 在项目里都应该被视为“命令执行通道”。前端不应该关心命令在哪里执行，只需要监听统一的运行事件：

```json
{
  "run_id": "run_xxx",
  "type": "stdout",
  "line": "solver output"
}
```

后续应把执行逻辑抽象为 Runner：

- `LocalRunner`
- `SshRunner`
- `WslRunner`
- `DockerRunner`
- `SlurmRunner`
