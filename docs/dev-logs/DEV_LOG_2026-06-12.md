# Dev Log 2026-06-12 — pip 安装模式、方法实验室、分发层架构

## 核心决策

### 技术栈分层：三条安装路径
之前所有功能绑定 Tauri 桌面壳，安装需要 Python + Node + Rust + VS Build Tools 四件套。
今天将安装路径拆分为三层，让新用户能 `pip install` 后直接浏览器打开。

| 路径 | 命令 | 依赖 | 受众 |
|------|------|------|------|
| pip 安装 | `simfea-studio` | 仅 Python | 所有用户 |
| 前端开发 | `pnpm dev:frontend` | Python + Node | 改 UI |
| 桌面版 | `pnpm dev:tauri` | Python + Node + Rust | 原生窗口 |

Tauri 保留但不再作为唯一入口。README 重写为三条路径独立展示。

### FastAPI 完全独立化
`python src/backends/main.py` 之前只能通过 Tauri sidecar 启动（依赖 stdin 管道监听生命周期命令）。修改 `if __name__ == "__main__"` 块，用 `sys.stdin.isatty()` 自动检测运行上下文：
- 终端模式 → `uvicorn.run()` 直接启动
- 管道模式 → `start_input_thread() + start_api_server()` (Tauri sidecar)

新增 `cli.py` 入口（`simfea-studio` 命令）：启动服务器 + 自动打开浏览器。
