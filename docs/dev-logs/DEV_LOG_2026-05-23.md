### 安装流程

```
POST /install → 202 { install_id }
  → SSE events/{install_id}:
      install_progress (download  0%→40%)
      install_progress (extract  40%→80%)
      install_progress (scan     80%→90%)
      install_progress (verify   90%→100%)
      install_complete { SolverInstallation }
      或 install_error  { message }
```

### 关键设计决策

- 下载 URL 硬编码 Windows 包 `ccx_2.21_win64.zip`（不做跨平台）
- zip 解压前对每个 `member_path.resolve()` 做路径穿越检查
- 下载 + 解压共用一个 try/finally 确保 zip 临时文件在所有路径下被删除
- 不自动检测已有 CalculiX（"自动搜索"按钮已有此功能）
- 不做断点续传、不做 SHA256 校验（依赖 zip 内建 CRC）
