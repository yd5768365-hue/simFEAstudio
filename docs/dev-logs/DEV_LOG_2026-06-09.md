# Dev Log 2026-06-09 — 项目状态总结与 AI 功能上线

## 完成内容

### AI 管道
- 接入 Ollama 本地大模型：qwen2.5:7b (4.7GB, RTX 3060 12GB 显存全容纳)
- 嵌入模型：nomic-embed-text (274MB, 768 维向量)
- 通用对话 (completions) + 嵌入生成 (embeddings) + RAG 上下文问答 (chat_with_context)

### 知识库 RAG
- SQLite 向量存储 (documents + chunks 表)
- 文档摄取管道：PDF( PyPDF2) / Markdown / 纯文本 → 500 字分块 + 50 字重叠 → Ollama 嵌入 → 存库
- 余弦相似度检索 (numpy + 暴力搜索, 适用文档量小的场景)
- API: 上传/列出/删除文档, RAG 问答 (POST /v1/knowledge/ask)

### AI 聊天界面
- ChatGPT 风格多轮对话, 消息历史保留
- 三个独立面板: 历史记录 / 关联运行 / 知识库选择
- 文件路径直接索引 (输入本机路径 → 后端读取并索引)
- 对话历史 localStorage 持久化 (最多 20 条)
- SVG 图标替代 emoji, 标准化聊天 UI

### 实验编辑器

- 支持 .py / .ipynb / .md 文件
