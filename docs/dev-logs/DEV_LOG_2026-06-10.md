### H. BenchmarkLab 布局最终重写

经历多次迭代后，最终方案：**完全复用 ExperimentLab 的 CSS 类名和 DOM 结构**。

```html
<!-- 两个组件共享相同的骨架 -->
<div class="lab">
  <div class="lab-top">    ← 顶栏
  <div class="lab-body">   ← flex row
    <nav class="lab-sidebar">  ← 200px 侧栏
    <div class="lab-main">     ← flex:1 主区域
      <div class="lab-preview"> ← 滚动内容区
```

关键修复：
- 单容器滚动：`.lab-preview` 是唯一滚动区，消除点击案例时"缩小"问题
- `.lab-main` → `display:flex; flex-direction:column; min-height:0`
- `.lab-preview` → `flex:1; overflow-y:auto`
- 统计条和对比表放入 `.lab-preview` 内，随文档自然滚动
