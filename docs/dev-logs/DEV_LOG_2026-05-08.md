```text

```

## result_summary.json

标准摘要文件位置：

```text
.simfea/runs/<run_id>/artifacts/result_summary.json
```

核心字段：

```json
{
  "schema_version": "simfea.result-summary.v1",
  "case_type": "cantilever_beam",
  "solver": "demo-shell",
  "runner": "SSHRunner",
  "scheduler": {
    "name": "",
    "job_id": "",
    "partition": "",
    "allocated_node": ""
  },
  "metrics": {
    "max_displacement_mm": 0.421,
    "max_von_mises_mpa": 128.6
  },
  "artifacts": [
    "artifacts/result.txt"
  ],
  "visualization": {
    "kind": "cantilever_beam",
    "ready": true
  }
}
```
