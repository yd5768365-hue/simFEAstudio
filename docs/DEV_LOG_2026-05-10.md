## VTK 最小链路

后端生成：

```text
.simfea/runs/<run_id>/artifacts/cantilever_result.vtk
```

并在摘要中写入：

```json
{
  "visualization": {
    "vtk_artifact": "artifacts/cantilever_result.vtk"
  }
}
```

前端通过接口读取：

```text
GET /v1/runs/{run_id}/artifacts/{artifact_path}
```

然后由 VTK.js 渲染。

## 学习记录导出升级

背景判断：

- 运行归档目录 `.simfea/runs/<run_id>/` 适合保存一次计算的完整证据。
- 长期学习沉淀还需要一个独立目录，方便用户用 Obsidian、VS Code、AI agent 或全文检索工具长期整理。
- 因此新增“学习库导出”能力：运行证据仍在物证仓库中，用户可以把选中运行额外导出为学习记录。

配置入口：

```json
{
  "learning": {
    "export_root": ".simfea/learning",
    "default_format": "md",
    "formats": ["md", "json", "txt"]
  }
}
```

后端变化：

- `AppSettings` 新增 `learning_export_root`、`learning_formats`、`learning_default_format`。
- `GET /v1/config` 与 `GET /v1/connect` 返回学习库目录和可用格式。
- 新增 `POST /v1/runs/{run_id}/learning-export`。
- 导出前会刷新 `result_summary.json` 和 `learning_report.md`。
- 支持格式：
  - `md`：直接导出可阅读的学习沉淀报告。
  - `json`：导出结构化记录，包含 metadata、summary、note、report、artifacts，方便其他 AI agent 读取。
  - `txt`：导出纯文本记录，方便快速检索。
- 成功导出后，`meta.json` 写入 `learning_export` 和 `learning_exports`，用于前端显示最近导出位置。

前端变化：

- 侧车连接信息增加“学习库”路径。
- 新增“学习记录导出”面板。
- 用户可以临时输入导出目录，也可以使用 `.simfea/config.json` 中的默认目录。
- 用户可以从后端配置的格式列表里选择 `md/json/txt`。

后续建议：

- 增加桌面目录选择器，减少手动输入路径。
- 增加导出模板，例如“课程笔记模板”“算例复盘模板”“导师汇报模板”。
- 在 JSON 导出基础上建立学习记录索引，后续支持按求解器、节点、结果指标检索。
