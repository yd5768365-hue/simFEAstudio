# Development Log Location

Formal long-term development logs for SimFEA Studio and SimFEA-Lab should be written to:

```text
H:\知识库\我的ai时代知识库\有限元与仿真\独立开发求解器--日志
```

SimFEA Studio is the workflow and comparison workbench. It should record case-management progress, comparison-case design, workflow changes, and links to solver outputs in the knowledge-base log folder above.

SimFEA-Lab is a separate solver-development project. When solver-core progress affects Studio workflows or comparison cases, update the same knowledge-base log folder so the two projects stay synchronized.

Existing historical logs in this `docs` folder are kept as project history. New formal long-term logs should point to the knowledge-base folder.
